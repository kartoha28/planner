# TaskFlow — Локальний PWA-планувальник задач

Мобільний та десктопний **PWA-планувальник задач** на **Vue 3 + Vite + TypeScript**, створений на базі дизайн-системи **TaskFlow (Hi-Fi Light & Dark)**. Працює **повністю локально на пристрої** без серверів і баз даних.

## Можливості
- **Повністю локальна робота (`localStorage`)**: усі задачі, підзадачі, тема та стан сповіщень зберігаються локально на пристрої; є експорт і імпорт резервної копії у JSON.
- **PWA & Офлайн-режим**: кастомний Service Worker (`vite-plugin-pwa` + `Workbox`) кешує весь застосунок — працює без інтернету та встановлюється на робочий стіл або домашній екран смартфона (`180×180`, `192×192`, `512×512`, `maskable`).
- **Локальні Push-сповіщення**: нагадування для задач через Web Notifications API та `ServiceWorkerRegistration.showNotification()` без жодного push-сервера (включно з кнопкою тестування та швидким таймером у вкладці «Профіль»).
- **Світла і темна теми**: CSS-змінні для Light і Dark режимів з автоматичним визначенням системної теми та ручним перемиканням.
- **4 екрани**: «Сьогодні» (прогрес-картка, пошук, фільтри, список задач), «Календар» (день/тиждень, таймлайн), «Проєкти» (статистика по категоріях) і «Профіль» (тема, сповіщення, резервне копіювання).

## Локальний запуск
```bash
npm install
npm run dev
```

Для перевірки PWA (Service Worker + offline + сповіщення) у production-режимі:
```bash
npm run build
npm run preview
```

## Деплой на GitHub Pages
У репозиторії налаштовано workflow `.github/workflows/deploy.yml`, який автоматично збирає застосунок із `GITHUB_ACTIONS=true` (`base: /planner/`) і публікує на GitHub Pages при кожному `push` у гілку `main`.

> У налаштуваннях репозиторію на GitHub (**Settings → Pages → Build and deployment → Source**) потрібно вибрати **GitHub Actions**.
